# Maison Larder — Artisanal Pantry, Chef Provisions & Catering

Curated culinary collective offering small-batch artisanal pantry goods, ready-to-heat chef provisions, and bespoke private dining catering.

## About

Maison Larder is a European gourmet larder cooked for your table. We source small-lot pantry staples directly from regional estates and family mills — cold-pressed Andalucían olive oil, foraged golden chanterelles, 36-month Parmigiano-Reggiano, and heritage-breed beef — and prepare ready-to-heat chef suppers in our 12 Eziobodo kitchen, packed chilled in glass, linen, and stoneware.

**Kitchen & Larder Counter:** 12 Eziobodo · open Tuesday–Sunday, 10:00–19:00

## Site sections

- **Home** — hero showcase, this week's larder selection, weekly supper spotlight, catering preview, provenance ledger, and client testimonials.
- **Chef Provisions** — ready-to-heat kitchen suppers and bronze-die pastas, prepared fresh every Thursday and Friday.
- **Artisanal Pantry** — oils, raw honeys, and cellar staples bottled at partner groves, mountain apiaries, and family mills.
- **Private Catering** — three curated banquet tiers: The Larder Table (family-style, 12–24 guests), The Cellar Tasting (four-course plated, 16–40 guests), and The Estate Banquet (full-service chef & sommelier, 30–90 guests).
- **Kitchen & Provenance** — ingredient sourcing ledger tracing every jar to its estate, producer, and harvest spec.
- **Contact** — counter hours, private catering inquiries, and weekly harvest dispatch signup.

## Tech stack

- React 19, Vite, TypeScript

- lucide-react, motion, Express
- @google/genai

## Getting started

```bash
# install dependencies
npm install

# run dev server (http://localhost:3000)
npm run dev

# build for production
npm run build

# preview production build
npm run preview

# typecheck / lint
npm run lint
```

## Deployment

Build artifacts are emitted to `dist/`. Deploy the contents of `dist/` to any static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages, etc.).
